# Competitor profile: Kinnu

Last updated: 2026-08-28

## Executive assessment

Kinnu is strong at turning broad knowledge into short, cohesive concept units and making retention visible. Its defensible product loop is not “short lessons” alone; it combines narrative pathways, retrieval variation, memory prediction, and low-punishment consistency mechanics.

T1GER should borrow those learning mechanics, not clone Kinnu's identity. T1GER's stronger strategic wedge is closing the gap between knowing and doing: an Orb unlocks a Field Mission, and only submitted Proof of Work secures the full reward, Build Vault artifact, streak protection, and pet recovery.

## Product model

| Dimension | Kinnu | T1GER response |
|---|---|---|
| Unit | Cohesive Orb | Tactical Orb with one decision-changing model |
| Structure | Storified pathway | Skill tree with prerequisites and visible execution outcome |
| Recall | Adaptive games and Knowledge Bank | FSRS Memory Shield with Smart Review |
| Consistency | Crane Stamps | Dual learning/execution streak plus T1GER vitals |
| Completion | Learning session | Learning mastery plus real-world Proof of Work |
| Output | Knowledge retained | Knowledge retained and artifact created |

## Strengths

- Clear atomic content model.
- Evidence-led experimentation around schemas, narratives, case studies, and retrieval formats.
- Retention is a visible product object rather than a hidden scheduler.
- The map gives users direction without exposing a conventional course catalog.
- Consistency rewards avoid the all-or-nothing punishment of fragile streaks.

## Gaps T1GER can exploit

- General knowledge has weak external proof that behavior changed.
- Learning sessions do not inherently create portfolio-grade evidence.
- Broad topic coverage can dilute a sharp outcome promise.
- T1GER can connect learning, execution, social proof, verified XP, and a living mascot in one causal loop.

## Product decisions implemented

1. Every launch lesson now carries a structured Orb learning design: curiosity question, prediction, three story beats, misconception, three summary points, and retrieval anchor.
2. LEARN presents the Orb in Prime → Story → Schema micro-transitions before the challenge.
3. Knowledge Bank exposes memory health and Orb-level retention.
4. Smart Review updates FSRS memory cards without duplicating completion XP, streak rescue, or artifacts.
5. Existing Learn → Field Mission → proof submission → Build Vault remains the non-negotiable completion bridge.

## Metrics to monitor

- Orb start → challenge completion.
- Challenge completion → Field Mission start.
- Field Mission start → verified proof submission.
- Seven- and thirty-day concept retention.
- Smart Review completion and post-review recall.
- Artifacts per weekly active learner.
